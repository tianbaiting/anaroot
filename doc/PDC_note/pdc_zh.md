  我为 PDC 的阴极读出室编写了通用分析程序。首先，限制时间窗口和宽度阈值。这里，我们采用了 60 ch

  理解 PDC 感应信号的响应函数非常重要。我们已经知道 SECHS 函数是一个非常好的近似：
  f(x|α,μ, δ) = a / cosh²(π(x − μ)/σ)

  这里的质心 μ 可以表示为：
  μ = (σ/π) * tanh⁻¹( (√Q₁/Q₃ - √Q₁/Q₂) / (2sinh(πw/σ)) )
  σ = (πw) / (2cosh⁻¹( ½(√Q₁/Q₃ + √Q₁/Q₂) ))

  这里 w 是 PDC 的条带尺寸，为 12 mm。在 NIMA638(11)_134 中可以找到更有用的公式（但有错别字），用于
  GANIL_MAYA：
  μ = (w/2) * (log(1 + a₁) – log(1 – a₁)) / (log(a₂ + √a₂² - 1))
  a₁ = ½ * (√Q₁/Q₃ - √Q₁/Q₂) / √a₂² - 1
  a₂ = ½ * (√Q₁/Q₃ + √Q₁/Q₂)

  除了 SECHS，我们还从参考文献 NIMA366(95) 298 中准备了几个响应函数，例如 COG、COGW、Lorentzian 和
  Gaussian。

   - COG (重心::加权位置): x = x₀ + μ = Σ(qᵢxᵢ) / Σqᵢ
   - COGW (带偏置的重心): x = x₀ + μ = Σ(qᵢ²xᵢ) / Σqᵢ²
   - Lorentzian: μ = w/2 * (Q₁Q₂ - Q₂Q₃) / (Q₁Q₃ + Q₁Q₂ - 2Q₂Q₃)
   - Gaussian: μ = w * (log(Q₁/Q₃) - log(Q₁/Q₂)) / (2 * (log(Q₁/Q₃) + log(Q₁/Q₂)))

  此过程中的一个可能问题是 ToT
  信息的非线性，这很难估计。另一种方法可以应用于调整邻近通道间电荷差异的位置唯象确定，该方法曾用于 CNS 的
  SRPPAC。我们正在研究用 PDC 推断位置的最佳方法。

  CRM的响应函数采用了SECHS，但它是经过积分的：

  q(X) = (1/2D) * ∫[X-w/2, X+w/2] (1/cosh(πX'/D)) dX' = (1/π) * [atan(e^π(X+w/2)) - atan(e^π(X-w/2))]

  电荷比 R = (qᵢ - qᵢ₊₁)/(qᵢ - qᵢ₋₁) 可以从给定的实验数据中得出位置。

  “电荷”的一个主要变化是如何将总Tot相加。总Tot现在通过以下方式计算：

  W_T = Σ Wᵢ
  Q^T = Σ Qᵢ = k₀e^(W_T/τ) ≠ k₀e^(ΣWᵢ/τ) = k₀e^(<W>/τ)

  在PDC分析中执行了以下步骤：
   1. 像往常一样收集Hit-Class。
   2. 使用TDC和ToT信息过滤Hit事件，稍后转换为电荷信息。
   3. 根据通道信息（相邻的）对存活的hit进行排序和聚类。
   4. 在聚类中，根据电荷信息进一步对子聚类进行分类（最多三个子聚类）。
   5. 用选定的方法1-4（3：SECHS，4：CRM）推断每个聚类的位置。
   6. 计算U-V平面两组中的所有组合，然后计算卡方值，除了U-V平面外还包括X-plane。然后，填入Track-Class。
   7. 根据卡方值对Track-Class进行排序。
   8. （为改进而研究中）使用具有较差卡方值的已用径迹移除该径迹。
